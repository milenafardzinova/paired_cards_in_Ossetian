# 1. Название проекта
Компьютерная игра «Парные карточки» для изучения осетинского языка.

# 2. Короткое описание назначения проекта
Компьютерная игра для изучения осетинского языка, повторения знакомых и изучения новых слов через ассоциацию изображений, текста и звука. Игрок тренирует память, сопоставляя парные карточки с картинками и подписями на русском и осетинском языках.

**Правила игры:**
* Карточки расположены на поле в виде сетки 4 на 4 (всего 8 пар).
* Игрок кликает на закрытые карточки («рубашкой»), чтобы открыть их. Одновременно могут быть открыты только две карточки.
* Если пара совпала — обе остаются открытыми (отгаданными).
* Если не совпала — они автоматически закрываются обратно через 600 миллисекунд.

# 3. Функциональные возможности
* **Выбор темы перед игрой:** На первой форме игрок выбирает одну из тем: «Цæрæгойтæ (Животные)» или «Хæринаг (Еда)». От выбранной темы зависит набор слов (8 пар карточек).
* **Выбор уровня сложности с блокировкой:** Изначально доступен только Уровень 1. После победы на Уровне 1 разблокируется Уровень 2, после победы на Уровне 2 — Уровень 3.
* **Подача материала по уровням:**
  * *Уровень 1 (легкий):* на обеих карточках пары есть картинка + подпись на русском + подпись на осетинском.
  * *Уровень 2 (средний):* одна карточка — только картинка (без подписей), вторая — только надпись на осетинском (без картинки).
  * *Уровень 3 (сложный):* одна карточка — только надпись на русском, вторая — только надпись на осетинском (без картинок).
* **Игровое поле:** Работает в виде матрицы (двумерный массив) 4×4.
* **Интерактивный звук:** Звук проигрывается только для карточек на осетинском в двух случаях:
- Когда игрок открывает закрытую карточку (переворачивает рубашку).
- Когда игрок кликает на уже открытую карточку.
* **Сохранение и чтение данных:** Автоматическая загрузка профилей при старте и запись обновленного прогресса игрока в файл формата JSON без дублирования пользователей.

# 4. Руководство администратора
* **Операционная система:** Windows 10 / 11.
* **Платформа:** .NET Framework 4.7.2.+
* **Файловая структура:** В папке с исполняемым `.exe` файлом должны находиться:
  * Файл базы данных `saves.json` (при первом запуске должен содержать структуру `{"Items":[]}`).
  * Папка `sounds/` с аудиофайлами `.wav` для озвучки, разделенными по темам (`Animals`, `Food`).
  * Папка `images/cards/` с файлом рубашки `back.jpg` и подкаталогами:
    * `/russian/` — содержит папки по темам, внутри которых находятся три уровня (`1Level`, `2Level`, `3Level`).
    * `/ossetian/` — содержит папки по темам, внутри которых находятся только два уровня (`1Level`, `2Level`), так как для 2 и 3 уровней сложности в осетинских карточках используются одни и те же файлы картинок-надписей.

# 5. Руководство пользователя
1. Запустите файл `project_paired_cards_in_Ossetian.exe`.
2. Введите ваше имя в текстовое поле (поле обязательно для заполнения).
3. Нажмите на одну из кнопок выбора темы: «Животные» или «Еда».
4. В окне выбора сложности нажмите на доступный уровень (изначально открыт только первый, заблокированные уровни окрашены в серый цвет).
5. На игровом поле поочередно открывайте карточки кликом мыши, пытаясь найти совпадающие пары.
6. Для управления аудиосопровождением используйте кнопку «Звук вкл/выкл», расположенную на форме игры.
7. После открытия всех пар появится сообщение о победе, игра автоматически сохранит прогресс в файл и закроет форму.

# 6. Руководство программиста
Приложение реализовано на языке C# (Windows Forms). Проект разделен на логические классы и слой графического интерфейса:

### Логические классы проекта:

#### 1. Класс `Card` (Игровая карточка)
* **Свойства:**
  * `Name` (`string`, `private set`) — уникальный идентификатор слова (имя файла без расширения).
  * `Language` (`string`, `private set`) — язык карточки (`russian` или `ossetian`).
  * `Image` (`Image`, `private set`) — графическое изображение лицевой стороны.
  * `IsOpened` (`bool`, `private set`) — флаг, открыта ли карта в текущем ходе.
  * `IsMatched` (`bool`, `private set`) — флаг, найдена ли для карты постоянная пара.
  * `CardTheme` (`string`, `private set`) — тема карточки (`Animals` или `Food`).
  * `CardLevel` (`int`, `private set`) — уровень сложности карточки.
* **Методы:**
  * `GetImagePath()` — формирует строку пути к PNG-файлу на основе языка, темы и уровня сложности.
  * `Open()` / `Close()` — изменяют состояние флага `IsOpened`.
  * `MarkAsMatched()` — переводит карту в статус разгаданной (`IsMatched = true`, `IsOpened = true`).
  * `IsPairFor(Card otherCard)` — логическая проверка: совпадают ли имена `Name` у двух разных объектов карт.

#### 2. Класс `GameField` (Управление игровым полем)
* **Поля и свойства:**
  * `cardGrid` (`Card[,]`) — двумерный массив (матрица) размером 4х4 для размещения карт на поле.
  * `cards` (`List<Card>`) — линейный список для промежуточного хранения 16 карт.
  * `FirstSelectedCard` / `SecondSelectedCard` (`Card`, `private set`) — ссылки на первую и вторую открытые игроком карты в текущем ходе.
  * `enum TurnResult` — перечисление результатов хода: `FirstCardOpened`, `MatchFound`, `WrongPair`.
* **Методы:**
  * `GetCardNamesFromfolder()` — считывает имена доступных файлов `.png` из папки выбранной темы.
  * `LoadLanguageCardPairs()` — выбирает 8 случайных уникальных имен слов и создает для каждого пару из русской и осетинской карточек.
  * `ShuffledCards()` — перемешивает список карт случайным образом.
  * `CreateField()` — заполняет матрицу `cardGrid` картами из перемешанного списка.
  * `SelectCard(Card clickedCard)` — обрабатывает клик по карте, управляет логикой ходов и возвращает `TurnResult`.
  * `CheckWinCondition()` — проверяет матрицу: если не осталось карт с `IsMatched == false`, фиксирует победу.
  * `CloseUnmatchedCards()` — закрывает несовпавшие карты и сбрасывает ссылки текущего хода.

#### 3. Класс `PlayerData` (Данные игрока)
* **Свойства:**
  * `Name` (`string`) — имя пользователя.
  * `MaxUnlockedAnimals` (`int`) — максимальный открытый уровень для темы «Животные» (по умолчанию 1).
  * `MaxUnlockedFood` (`int`) — максимальный открытый уровень для темы «Еда» (по умолчанию 1).
* **Методы:**
  * `Update(PlayerData newPlayerData)` — сравнивает и перезаписывает прогресс уровней только в большую сторону.

#### 4. Класс `UsersRepository` (Репозиторий пользователей)
* **Свойства и методы:**
  * `Items` (`List<PlayerData>`) — список всех зарегистрированных игроков.
  * `Add(PlayerData newUser)` — ищет игрока по имени. Если он существует — обновляет его максимальный прогресс через `Update()`, если нет — добавляет нового пользователя.

#### 5. Класс `SoundManager` (Управление аудио)
* **Методы:**
  * `PlayVoice(Card card)` — воспроизводит файл `.wav` для осетинской карточки с помощью системного класса `SoundPlayer` (с проверкой флага активности звука).

### Слой графического интерфейса (Windows Forms):
* `FormChooseTheme` — стартовое окно. Отвечает за ввод имени, выбор темы («Животные»/«Еда»), чтение JSON через `JsonSerializer.Deserialize` и запуск следующей формы.
* `FormLevelSelect` — окно выбора сложности. Считывает прогресс игрока и блокирует кнопки уровней (`Enabled = false`, цвет `DarkGray`), если предыдущий уровень не пройден.
* `FormGame` — основное окно игры. Содержит сетку `DataGridView`, визуализирует матрицу 4х4, обрабатывает клики в методе `dataGridViewField_CellClick` и осуществляет запись обновленного JSON-репозитория в файл `saves.json` при победе.
