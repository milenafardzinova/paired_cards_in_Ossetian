# Техническое задание
## Игра «Парные карточки»

### 1. Назначение разработки
Компьютерная игра для изучения осетинского языка, повторения знакомых и изучения новых слов через ассоциацию изображений, текста и звука. Игрок тренирует память, сопоставляя парные карточки с картинками и подписями на русском и осетинском языках.

### 2. Целевая аудитория
Игра подойдет всем, кто хочет изучать осетинский язык или повторять знакомые слова: детям, школьникам, взрослым, начинающим. Также игра заинтересует тех, кто любит жанр «мемори» (найди пару). Дополнительно игра полезна преподавателям осетинского языка для занятий.

### 3. Требования к программе или программному изделию

**a. Выбор темы (категории слов) перед игрой.**  
На первой форме игрок выбирает одну из тем: «Цæрæгойтæ (Животные)», «Хæринаг (Еда)». От выбранной темы зависит набор слов (8 пар карточек).

**b. Выбор уровня сложности с блокировкой.**  
Игрок видит три уровня (1, 2, 3). Изначально доступен только Уровень 1. После победы на Уровне 1 разблокируется Уровень 2, после победы на Уровне 2 — Уровень 3. Уровни отличаются подачей материала:
- Уровень 1 (легкий): на обеих карточках пары есть картинка + подпись на русском + подпись на осетинском.
- Уровень 2 (средний): одна карточка — только картинка (без подписей), вторая — только надпись на осетинском (без картинки).
- Уровень 3 (сложный): одна карточка — только надпись на русском, вторая — только надпись на осетинском (без картинок).

**c. Игровое поле в виде матрицы (двумерный массив) 4×4.**  
Карточки расположены в виде сетки 4 на 4 (8 пар). Игрок кликает на закрытые карточки («рубашкой»), чтобы открыть их. Одновременно открыты только две карточки.
- Если пара совпала — обе остаются открытыми (отгаданными).
- Не совпала — закрываются.

**d. Звук.**  
Звук проигрывается только в двух случаях:
- Когда игрок открывает закрытую карточку (переворачивает рубашку).
- Когда игрок кликает на уже открытую карточку.

Кнопка «Звук вкл/выкл» полностью отключает звук.
